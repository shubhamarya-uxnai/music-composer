# BA design-system integration

The Acoustic Matrix frontend is a React app in `react-app/`. It imports `@ba-design-system/react`, `@ba-design-system/react/styles.css`, and the shared consumer stylesheet from the sibling `va-design-system` checkout at build time. The published site contains the compiled result and does not require the BA CDN at runtime.

`react-app/src/ui.tsx` is the component adapter. Product code uses `Action`, `IconAction`, `Field` (`InputField`), `Surface`, `Select`, `Loader`, and `ProgressBar`, plus BA semantic `Page`, `Display`, and `Sidebar` attributes. BA buttons, Material Symbol icon buttons, input fields, loaders, and progress indicators are mapped there (alongside re-exported `StatusChip`, `Choice`, `ProgressPie`, `ProgressDonut`, `SegmentedProgress`, and `Stepper`). `Select` remains a native control until BA publishes a tested Dropdown; replacing that one adapter function is the intended upgrade path. `Loader` and `ProgressBar` are wired into the local audio analysis status panel and link-check flow via custom events emitted by `app/app.js`. New BA components are adopted deliberately after checking their behavior and appearance rather than automatically inheriting an unreviewed variant.

The audio analysis and canvas renderer remain in `app/app.js`. React mounts stable controls before loading that engine, so file upload, view mode, scale, zoom, pan, colors, and playback retain their existing behavior. `legacy.html` is the preserved pre-React page.

Build from `react-app/` with `npm run build`. The BA checkout is expected at `../../../va-design-system` relative to that directory, or set `BA_DESIGN_SYSTEM_DIR`. The output goes to the repository root for GitHub Pages. Vite uses relative asset URLs because this is a GitHub Pages project subpath.
